## 복대리로 할 수 있는 일

AI와 나눈 대화를 바탕으로 상담 내용을 준비하고, 복대리에 상담을 신청할 수 있습니다. 접수 후에는 진행 상태와 연결된 변호사 정보를 확인합니다. 변호사 수락 전에는 상담 내용을 수정하거나 신청을 철회할 수 있습니다.

## 연결하기

사용 중인 AI 서비스의 **MCP 서버 추가** 설정에 아래 주소를 입력하고, 연결 승인을 진행하세요.

```text
https://mcp.bokdaeri.com/mcp/agent
```

원격 MCP와 OAuth를 지원하는 클라이언트가 필요합니다. 지원 클라이언트는 동적 등록(DCR)을 이용할 수 있어 별도의 사전 등록 요청이 필요하지 않습니다.

[단계별 연결 방법](docs/connecting.md) · [지원 환경과 확인 범위](docs/compatibility.md)

**브라우저를 조작하는 에이전트라면** MCP 연결 없이 [에이전트 이용 안내](https://mcp.bokdaeri.com/agents)에서 웹 신청을 시작할 수도 있습니다.

## 이렇게 요청해 보세요

> 임대차보증금을 돌려받지 못하고 있어요. 복대리에서 변호사 상담을 신청하고 싶어요. 상담 내용을 정리하고 신청을 도와주세요.

1. **내용 준비** — AI와 상담할 내용을 정리합니다.
2. **확인 후 신청** — 복대리 웹 화면에서 번호 인증, 필수 동의와 최종 확인을 진행합니다.
3. **결과 확인** — 접수 상태를 확인하고, 요청을 수락한 변호사의 연락을 기다립니다.

초안 작성이나 번호 인증만으로 접수되지는 않습니다. 접수 이후에는 “진행 상태를 확인해 줘”, “상담 내용을 수정해 줘”처럼 요청할 수 있습니다. [상태 조회·수정·철회 예시](docs/usage.md)

## 이용 안내

- **비용:** 첫 상담 문의에는 비용이 없습니다. 추가 상담·사건 의뢰 비용은 변호사와 협의합니다.
- **정보 제공:** 상담 내용은 참여 변호사가 확인하며, 연락처는 요청을 수락한 변호사 한 명에게 제공됩니다.
- **진행 상태:** 조회 시점의 결과를 안내합니다. 변호사 수락과 실제 통화·상담 완료는 구분됩니다.

인증 조건과 지원 환경은 [연결 안내](docs/connecting.md)와 [자주 묻는 질문](docs/faq.md)에서 확인해 주세요.
