# Privacy and verification · 개인정보·인증 안내

[English](../README.en.md) · [한국어](../README.ko.md) · [Official privacy policy](https://mcp.bokdaeri.com/agents/policies/privacy)

## Before submission

- OAuth authorizes the assistant's connection. It does not replace the phone verification, required consent or final consultation confirmation.
- A domestic South Korean `010` mobile number that can receive the verification SMS is required.
- For this generic MCP connection, enter the verification code on the Bokdaeri page presented by the service. Do not send verification codes, cookies or tokens as MCP arguments or in a public issue.
- Review the final consultation details, first-inquiry cost and information-sharing scope. A preview or verification alone does not create a consultation.
- Consultation details are available to participating lawyers for review. The phone number is provided to the lawyer who accepts the request under the service's consent process.

## 신청 전 확인

- OAuth는 AI 연결에 대한 승인입니다. 번호 인증·필수 동의·상담 최종 확인을 대신하지 않습니다.
- 인증 문자를 받을 수 있는 국내 `010` 휴대전화번호가 필요합니다.
- 이 범용 MCP 연결에서는 복대리가 제시한 웹 화면에 인증번호를 입력합니다. 인증번호·쿠키·토큰을 MCP 도구 인자나 공개 이슈에 보내지 마세요.
- 최종 상담 내용·첫 문의 비용·정보 제공 범위를 확인합니다. 미리보기나 인증만으로는 접수되지 않습니다.
- 상담 내용은 참여 변호사가 확인하고, 전화번호는 요청을 수락한 변호사 한 명에게 서비스 동의 절차에 따라 제공됩니다.

## Data and account help · 정보·연결 관리

The service's current retention periods and data rights are described in the [privacy policy](https://mcp.bokdaeri.com/agents/policies/privacy). Use your client's connection controls to disconnect the MCP integration. For data-access or deletion requests, contact [Bokdaeri support](mailto:admin@lawired.co.kr) through the official route. Verification may be required. Disconnecting an AI client does not itself withdraw a consultation or delete all records.

보관 기간과 개인정보 권리 안내는 [개인정보처리방침](https://mcp.bokdaeri.com/agents/policies/privacy)을 확인하세요. MCP 연결은 사용하는 AI 서비스의 연결 설정에서 해제할 수 있습니다. 개인정보 열람·삭제 등은 [복대리 공식 문의](mailto:admin@lawired.co.kr)로 요청하며, 본인확인이 필요할 수 있습니다. AI 연결 해제만으로 상담이 철회되거나 모든 기록이 삭제되지는 않습니다.

## Public reports · 공개 문의 주의

Do not include legal case details, names of parties, phone numbers, verification codes, access links containing personal session data, cookies, tokens or screenshots containing these in GitHub issues. Describe the affected feature and a non-sensitive error message instead. Send security or personal-data concerns through the support route above.

GitHub 이슈에는 실제 사건 내용·당사자 이름·전화번호·인증번호·개인 세션이 들어간 접근 링크·쿠키·토큰·해당 정보가 찍힌 화면을 올리지 마세요. 기능 이름과 민감하지 않은 오류 문구만 설명하고, 보안·개인정보 문의는 위 공식 문의 경로를 이용하세요.
